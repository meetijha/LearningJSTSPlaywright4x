# Learning JS TS Playwright 4x

This repository is a learning project focused on JavaScript, TypeScript, and Playwright automation.

## Overview

The goal of this repo is to practice core JavaScript fundamentals and gradually move into modern automation testing with Playwright.

## Project Structure

```text
LearningJSTSPlaywright4x/
├── 01_chapter_JS_Basics/
│   ├── 01_HelloWorld.js
│   └── 02_Math.js
├── README.md
└── .git/
```

## JavaScript Basics Covered

- Printing output with `console.log()`
- Basic arithmetic operations
- Writing simple script files and running them with Node.js

## Running the Files

From the project root, run:

```bash
node 01_chapter_JS_Basics/01_HelloWorld.js
node 01_chapter_JS_Basics/02_Math.js
```

## Notes

This is a beginner-friendly repo intended for learning and experimentation as the JavaScript and Playwright skills progress.
