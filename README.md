# LearningJS TS Playwright 4x

This repository is a simple JavaScript learning project focused on JavaScript basics and beginner concepts.

## Contents

- `01_chapter_JS_Basics/01_HelloWorld.js` - prints a basic Hello World message
- `01_chapter_JS_Basics/02_Math.js` - demonstrates a simple mathematical expression

## Purpose

The goal of this project is to practice core JavaScript fundamentals, including:

- syntax basics
- console output
- arithmetic operations
- working with JavaScript files in a learning environment

## Run a file

From the project root, use Node.js to run any script:

```bash
node 01_chapter_JS_Basics/01_HelloWorld.js
```
